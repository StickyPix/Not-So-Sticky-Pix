# Studio image-based lighting

`default_env_ibl.ktx` is the Filament-compatible neutral environment bundled
with Thermion's own examples and tests:

https://github.com/nmfisher/thermion/blob/main/examples/assets/default_env_ibl.ktx

Only the indirect-light data is loaded. The environment is not displayed as a
skybox, so the Flutter background remains unchanged.
